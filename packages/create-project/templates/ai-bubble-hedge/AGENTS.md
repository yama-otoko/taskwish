# TaskWish AI bubble hedge

This project uses TaskWish. Before planning or modifying code, read and follow
`.agents/skills/taskwish/SKILL.md` for the framework's architecture, APIs, and
conventions.

Never put TypeSafe API keys, brokerage credentials, account data, or other
secrets in prompts, client-side code, logs, or source control. Keep risk limits
in deterministic symbolic rules. This starter is a paper-trading example; do
not connect it to a live broker without a separately reviewed approval and
execution design.
