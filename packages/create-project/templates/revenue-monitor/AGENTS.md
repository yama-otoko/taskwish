# TaskWish revenue monitor

This project uses TaskWish. Before planning or modifying code, read and follow
`.agents/skills/taskwish/SKILL.md` for the framework's architecture, APIs, and
conventions.

Never place bank API credentials, access tokens, Slack tokens, account data, or
transaction data in prompts, client-side code, logs, or source control. Add
production-grade access controls, encryption, retention, and consent handling
before processing real financial data.
