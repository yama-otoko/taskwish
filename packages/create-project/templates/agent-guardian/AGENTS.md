# TaskWish agent guardian

This project uses TaskWish. Before planning or modifying code, read and follow
`.agents/skills/taskwish/SKILL.md` for the framework's architecture, APIs, and
conventions.

Never put TypeSafe API keys, customer secrets, authentication material, or
unredacted sensitive tool arguments in prompts, client-side code, logs, or
source control. Keep routing thresholds in deterministic code and require a
human for uncertain or irreversible decisions.
